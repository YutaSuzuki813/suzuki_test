# suzuki_test

このリポジトリには、ファイル管理を支援するユーティリティスクリプトが含まれています。

## ファイルコピーバッチスクリプト

`copy_files_confirm_allmode.bat` は、リストファイルに基づいてファイルを一括コピーするための使いやすいWindowsバッチスクリプトです。

### 主な特徴

- ✅ 簡単な使用方法 - デフォルト設定で引数なしでも実行可能
- ✅ 安全性 - 実行前の確認プロンプト
- ✅ 詳細な進捗表示 - 成功/失敗/スキップの件数を表示
- ✅ エラーハンドリング - 分かりやすいエラーメッセージ
- ✅ ヘルプ機能 - コマンドラインヘルプ（/?, -h, --help）

### クイックスタート

1. `copyfile.txt` にコピーしたいファイルのリストを記述
2. バッチファイルを実行:
   ```batch
   copy_files_confirm_allmode.bat
   ```

### 詳細なドキュメント

詳しい使用方法、設定、トラブルシューティングについては、[BATCH_USAGE_GUIDE.md](BATCH_USAGE_GUIDE.md) をご覧ください。
